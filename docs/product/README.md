# 政府采购招标文件合规审查知识作业平台产品文档

版本:: 1.0
状态:: 初稿

## 1. 文档包定位

本目录用于沉淀“政府采购招标文件合规审查知识作业平台”的产品说明。

这套文档围绕四个核心判断展开：

- 产品不是通用文档审查，而是政府采购招标文件合规审查；
- 产品不是简单 AI 审查工具，而是知识驱动的审查作业系统；
- LLM + Wiki 是知识生产和样板验证层，正式产品是知识治理和审查作业层；
- 多省份上线必须支持本地条款、本地知识包、本地算力和差异化品类。
