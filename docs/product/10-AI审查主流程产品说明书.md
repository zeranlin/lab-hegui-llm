# AI 审查主流程产品说明书

版本:: 1.0
状态:: 初稿
所属产品线:: AI 审查主流程线

## 1. 产品线定位

AI 审查主流程线负责管理待审政府采购招标文件从进入系统到输出风险结果的全过程。

它回答三个问题：

- 待审文件进来后怎么画像；
- 怎么按政府采购章节逐章审查；
- 风险怎么输出、复核和生成报告。

本产品线不是通用文档问答，而是政府采购招标文件合规审查工作台。

## 2. 输入对象

- 原始招标文件；
- 抽取文本；
- 文件章节；
- 文件画像规则；
- 地域知识包；
- 品类审查包；
- 风险审查点；
- 审查模板；
- AI 审查编排配置。

## 3. 标准流程

```text
文件上传
  -> 文件解析
  -> 章节识别
  -> 项目画像
  -> 知识路由
  -> 逐章审查
  -> 风险识别
  -> 风险聚合
  -> 审查结果生成
  -> 人工复核
  -> 审查报告导出
```

## 4. 文件上传和解析

支持格式：

- Word；
- PDF；
- WPS 文档；
- 文本；
- 平台导出文件。

解析要求：

- 保留页码或段落位置；
- 识别标题层级；
- 识别表格；
- 识别评分表；
- 识别资格条件表；
- 识别合同条款；
- 生成可回溯的原文片段。

## 5. 项目画像

项目画像是知识路由入口。

画像维度：

- 项目名称；
- 项目编号；
- 采购人；
- 代理机构；
- 预算金额；
- 采购方式；
- 评审方法；
- 采购品目；
- 标的属性；
- 所属行业；
- 适用省份；
- 适用平台；
- 是否专门面向中小企业；
- 是否接受联合体；
- 是否允许进口产品；
- 文件章节完整性；
- 初步风险入口。

画像输出必须带原文依据，不允许只输出 AI 猜测。

## 6. 知识路由

系统根据画像调用知识：

```text
全国通用知识
  -> 省份知识包
  -> 市级或平台知识包
  -> 采购方式知识
  -> 品类审查包
  -> 场景规则
  -> 章节审查点
```

示例：

```text
福建 + 公开招标 + 物业管理
  -> 全国规则
  -> 福建规则
  -> 福建平台规则
  -> 公开招标规则
  -> 物业管理审查包
```

```text
四川 + 公开招标 + 计算机设备
  -> 全国规则
  -> 四川规则
  -> 四川平台规则
  -> 货物类公开招标规则
  -> 计算机设备审查包
```

## 7. 逐章审查

系统应按政府采购招标文件章节审查：

| 章节 | 必查内容 |
| --- | --- |
| 招标公告 | 预算、采购方式、资格条件、政策适用 |
| 投标人须知 | 投标规则、无效投标、证明材料 |
| 资格条件 | 法定资格、特定资格、业绩、证书 |
| 采购需求 | 技术服务要求、人员配置、验收标准 |
| 评标办法 | 分值结构、评分因素、量化标准 |
| 政府采购政策 | 中小企业、节能环保、进口产品 |
| 合同条款 | 付款、验收、违约、服务期 |
| 投标文件格式 | 声明函、承诺函、证明材料 |

## 8. 风险识别

风险识别必须基于风险审查点，不允许 AI 自由发挥。

每个风险判断应经过：

- 命中触发信号；
- 匹配适用范围；
- 检查排除条件；
- 关联原文证据；
- 关联法规或知识依据；
- 输出风险等级；
- 给出修改建议。

## 9. 风险输出

每条风险字段：

- 风险编号；
- 风险标题；
- 结论类型；
- 风险等级；
- 风险类型；
- 所属章节；
- 原文位置；
- 原文内容；
- 问题说明；
- 关联审查点；
- 审查依据；
- 修改建议；
- 命中知识版本；
- 是否需人工复核。

## 10. 审查结果聚合

系统应支持：

- 按章节聚合；
- 按风险类型聚合；
- 按风险等级聚合；
- 按知识来源聚合；
- 合并重复风险；
- 标记待确认事项；
- 生成审查摘要。

## 11. 报告输出

报告类型：

- 内部审查报告；
- 风险清单；
- 采购人修改建议清单；
- 审查过程记录；
- 知识命中报告；
- 人工复核记录。

报告必须保留原文证据和依据链，不能只输出总结。

## 12. 省份和算力适配

AI 审查主流程必须根据上线环境选择本地知识和算力：

- 福建租户默认调用福建知识包和福建算力；
- 四川租户默认调用四川知识包和四川算力；
- 某省只上线物业品目时，只启用物业审查包；
- 某省只上线计算机品目时，只启用计算机设备审查包。

跨省知识不得默认混用，除非明确标记为全国通用。

## 13. 关键指标

- 文件解析成功率；
- 画像准确率；
- 章节识别准确率；
- 风险识别准确率；
- 原文定位准确率；
- 知识命中有效率；
- 人工修改率；
- 单份文件审查时长；
- 报告一次通过率。

## 14. 产品经理结论

AI 审查主流程的核心不是“让 AI 看一遍文件”，而是让 AI 在政府采购知识、属地规则、品类审查包和证据链约束下完成标准化审查动作。
