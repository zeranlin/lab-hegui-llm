# 产品定位说明书

版本:: 1.0
状态:: 初稿
产品名称:: 政府采购招标文件合规审查知识作业平台

## 1. 产品定位

本产品定位为：

```text
政府采购招标文件合规审查知识作业平台。
```

它面向政府采购文件发布前审查场景，围绕资格条件、采购需求、评审办法、政府采购政策、合同履约等核心内容，基于法规政策、地方规则、品类经验、历史复盘和 AI 审查能力，完成文件画像、逐章审查、风险定位、依据匹配、人工复核和知识回写。

产品目标不是替代审查人员，也不是替代财政监管执法，而是帮助采购人、采购代理机构、集中采购机构和内控审查人员提升招标文件合规性、一致性和审查效率。

## 2. 市场前提

政府采购招标文件合规审查并不是新需求。当前行业中已经存在多种审查方式：

- 线下人工审查；
- 线上流程审查；
- 模板和负面清单审查；
- 法务或内控节点审查；
- 普通 AI 文档审查尝试。

因此，本产品不能定位成“从无到有发明审查”，而应定位成：

```text
把已有审查从人和流程驱动，升级为知识和数据驱动。
```

## 3. 当前审查方式的不足

### 3.1 线下人工审查

优点：

- 经验丰富；
- 判断灵活；
- 能处理复杂语境。

不足：

- 口径受个人经验影响；
- 审查效率不稳定；
- 新人培养成本高；
- 经验难以沉淀；
- 复盘数据难以形成资产。

### 3.2 线上流程审查

优点：

- 流程可控；
- 节点可追踪；
- 材料完整性较好管理。

不足：

- 主要解决有没有走流程；
- 难以判断条款本身是否合规；
- 难以识别隐性限制竞争和评分不合理。

### 3.3 模板和清单审查

优点：

- 对明确规则有效；
- 容易推广；
- 便于标准化。

不足：

- 对复杂场景适配不足；
- 对品类差异和地方规则支持有限；
- 难以动态吸收人工复盘经验。

### 3.4 普通 AI 审查

优点：

- 阅读速度快；
- 能总结问题；
- 交互体验好。

不足：

- 容易依据不稳；
- 误报和漏报难解释；
- 缺少政府采购专业边界；
- 难以形成持续迭代的知识闭环。

## 4. 产品解决的问题

本产品重点解决七类问题：

| 问题 | 产品解决方式 |
| --- | --- |
| 审查口径不统一 | 建立统一知识库、风险审查点和输出口径 |
| 审查效率低 | AI 辅助画像、逐章审查和风险定位 |
| 隐性风险难发现 | 基于品类场景和历史复盘识别高频风险 |
| 依据链不完整 | 每条风险关联原文、审查点和法规依据 |
| 人工经验难沉淀 | 人工复核、漏报误报和知识回写闭环 |
| AI 不可控 | 用知识路由、审查矩阵和风险点约束 AI |
| 质量无法度量 | 建立准确率、漏报率、误报率、人工修改率等指标 |

## 5. 核心用户

### 5.1 采购人

关注：

- 发布前降低合规风险；
- 减少质疑投诉；
- 提升采购文件质量；
- 形成单位内控留痕。

### 5.2 采购代理机构

关注：

- 提升文件编制和审查效率；
- 降低重复修改；
- 统一项目经理审查口径；
- 提升代理服务质量。

### 5.3 集中采购机构

关注：

- 标准化审查作业；
- 品类审查经验沉淀；
- 批量项目质量控制；
- 建立高频风险库。

### 5.4 财政监管和内控辅助场景

关注：

- 前置风险识别；
- 监管规则落地；
- 项目风险追溯；
- 审查质量分析。

产品不替代监管执法结论，但可以提供辅助审查和风险预警。

## 6. 产品边界

本产品明确不做：

- 不做通用文档审查平台；
- 不做泛法律咨询平台；
- 不替代财政监管执法；
- 不替代专家最终判断；
- 不直接面向供应商提供投标策略；
- 不做合同全生命周期管理；
- 不做采购交易平台；
- 不把 AI 输出直接作为最终合规结论。

产品专注于政府采购招标文件发布前和审查过程中的合规风险识别、证据链输出和知识沉淀。

## 7. 核心能力

本产品核心能力包括：

- 政府采购审查知识治理；
- 招标文件解析和项目画像；
- 基于画像的知识路由；
- 按章节逐项审查；
- 风险识别和证据链输出；
- 人工复核和调整；
- 漏报误报复盘；
- 知识更新和版本管理；
- 审查质量指标分析。

## 8. 产品价值主张

对客户的价值主张：

```text
让政府采购招标文件审查更统一、更高效、更可追溯，并让审查经验持续沉淀为组织能力。
```

对公司的价值主张：

```text
以政府采购行业知识库为核心壁垒，构建 AI 时代可持续迭代的行业审查产品。
```

## 9. 一句话定位

本产品不是“AI 看文件”，而是：

```text
以政府采购行业知识为底座，驱动招标文件合规审查、人工复核和知识回写的审查质量系统。
```
