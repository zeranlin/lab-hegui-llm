# 核心对象与数据模型说明书

版本:: 1.0
状态:: 初稿
适用范围:: 政府采购招标文件合规审查知识作业平台

## 1. 文档目的

本文用于定义正式产品中的核心业务对象，为研发、算法、数据和产品设计提供统一语言。

当前 LLM + Wiki 样板中的页面、模板和双链，未来应抽象为结构化对象、对象关系和状态流。

## 17. 产品经理结论

核心对象设计必须体现政府采购行业特性、属地化上线特性和 LLM + Wiki 知识生产特性。只有对象模型清晰，后续权限、流程、审查任务、知识回写和指标分析才能落地。
