# 缺失类风险审查

类型:: 知识点
状态:: 有效
主题:: 缺失类风险
适用阶段:: 文件画像; 逐章审查
关联审查点:: [[wiki/25-风险审查点/采购需求不完整不明确]]; [[wiki/25-风险审查点/采购标的所属行业错误或缺失]]; [[wiki/25-风险审查点/付款方式和支付时限不明确]]; [[wiki/25-风险审查点/履约验收标准缺失或不可操作]]

## 定位

缺失类风险不是从某句问题原文直接得出，而是从“政府采购文件应当载明但文本没有载明、或载明不完整”得出。

这类风险最容易漏报，因此必须在逐章审查中单独检查。

## 高频缺失项

| 缺失对象 | 应检查内容 | 可能风险 |
| --- | --- | --- |
| 预算金额 | 是否有总预算、最高限价、分项预算、合计是否正确 | 供应商报价依据不完整，价格评审和合同价款不清 |
| 采购计划/标的 | 每个采购计划是否对应标的名称、数量、单位、行业 | 标的属性、中小企业声明函和报价口径不清 |
| 采购类型 | 货物、服务、工程或混合采购是否明确 | 采购方式、评审规则、合同模板适用错误 |
| 采购品目 | 品目名称和编码是否明确、是否与标的一致 | 政策适用、核心产品、进口产品和统计口径错误 |
| 所属行业 | 中小企业声明函所属行业是否明确、是否与标的匹配 | 中小企业政策适用错误 |
| 服务期限/交付期限 | 起止时间、服务周期、续签机制是否明确 | 报价边界和履约责任不清 |
| 联合体/分包 | 是否允许、限制理由、分包范围和责任是否明确 | 竞争范围和履约责任不清 |
| 付款方式 | 节点、比例、条件、支付时限、发票要求是否明确 | 合同履行争议和供应商报价风险 |
| 验收方案 | 验收主体、标准、周期、资料、整改复验是否明确 | 付款、考核、解除合同缺少依据 |
| 合同关键条款 | 价款、违约、保密、知识产权、数据归属是否完整 | 合同不可执行或显失公平 |

## 判断方法

1. 先判断该字段是否属于本项目必须载明的信息。
2. 再判断文件是否已经在其他章节完整载明。
3. 如果多处表述不一致，按“矛盾或不完整”处理。
4. 如果确实缺失，风险原文可以引用相邻表格、空白条款或章节标题。
5. 问题说明中写明“缺了什么、为什么应当有、会影响什么”。

## 输出口径

```text
风险标题：采购标的所属行业未完整列示，影响中小企业声明函填报
原文内容：第X行：服务需求明细表……
问题说明：该表应列明标的名称、数量、是否专门面向中小企业及所属行业，但第二采购计划仅列预算，未列明对应标的和所属行业。
关联审查点：采购需求不完整不明确；采购标的所属行业错误或缺失
```

## 常见误报

- 文件正文没有写，但附件或投标文件格式中已清楚写明，不列缺失。
- 缺少某个字段名称，但内容可从同一章节直接、唯一推导出来，优先列为优化建议。
- 合同模板留空但专用条款已有清楚约定，应判断是否存在衔接风险，不能机械列高风险。
