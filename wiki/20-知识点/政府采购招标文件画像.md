# 政府采购招标文件画像

类型:: 知识点
状态:: 有效
主题:: 文件画像
适用阶段:: ingest 后; 风险识别前
关联法规:: [[wiki/10-法规依据/政府采购法]]; [[wiki/10-法规依据/政府采购货物和服务招标投标管理办法-87号令]]; [[wiki/10-法规依据/政府采购需求管理办法]]
关联动作包:: [[wiki/20-知识点/物业管理动作化审查包]]

## 定位

政府采购招标文件画像，是收到新文件后、正式风险识别前的第一步。

目标不是判断风险，而是确认文件属于哪类政府采购文件、适用哪些规则、有哪些章节、后续应重点审查哪里。

```text
原始文件
  -> 文件画像
  -> 结构化条款抽取
  -> 风险审查点匹配
  -> 审查意见
```

## 画像维度

画像不是简单登记文件基本信息，而是为后续合规审查建立“适用规则 + 审查重点 + 风险入口”。建议每份文件至少形成以下五组画像。

### 1. 文件身份画像

- 文件名称
- 项目编号
- 项目名称
- 采购人
- 采购代理机构
- 公告或文件日期
- 文件类型：招标文件、磋商文件、谈判文件、询价通知书、资格预审文件等
- 包组、标段、采购计划编号

### 2. 采购制度画像

- 是否属于政府采购
- 采购方式
- 是否属于货物、服务、工程或混合采购
- 是否适用公开招标规则
- 是否涉及深圳地方政府采购规则
- 是否涉及框架协议、电子卖场、集中采购等特殊机制
- 是否采用综合评分法、最低评标价法或其他评审方法
- 是否评定分离
- 是否收取投标保证金、履约担保
- 是否可能适用框架协议采购、合作创新采购、电子卖场或集中采购目录规则

### 3. 采购对象画像

- 采购标的
- 采购品目和品目编码
- 标的所属行业
- 预算金额或最高限价
- 预算构成、分项限价、报价口径
- 服务期限或交付期限
- 是否长期服务项目
- 是否涉及公共安全、医疗、教育、信息化、运维、物业、工程建设等特殊场景
- 是否允许联合体
- 是否允许分包
- 是否接受进口产品
- 是否涉及核心产品
- 是否涉及强制节能、环境标志、CCC、绿色数据中心、等保、密评、数据安全
- 是否含硬件、软件、平台建设、运维、物业现场服务等复合内容

### 4. 政府采购政策画像

- 是否专门面向中小企业采购
- 是否设置价格扣除
- 中小企业声明函所属行业是否明确
- 是否涉及节能产品、环境标志产品、绿色数据中心、强制认证、监狱企业、残疾人福利性单位
- 是否涉及政府采购订单融资、信用信息、诚信分
- 是否存在采购标的所属行业与采购对象不一致的复核点
- 是否存在进口产品、国产产品、核心产品、首台套、创新产品等政策适用点

### 5. 文件结构画像

检查文件是否包含：

- 招标公告
- 投标人须知
- 资格性审查表
- 符合性审查表
- 采购需求或用户需求书
- 评分办法
- 投标文件格式
- 合同条款
- 政府采购政策条款
- 质疑投诉和诚信管理条款

### 6. 条款机制画像

对后续审查最有用的，不只是“有没有章节”，还要看文件如何设置竞争规则：

- 资格性审查：是否只设置法定资格，是否出现额外资质、业绩、人员、授权要求。
- 符合性审查：是否存在过多投标无效条款，是否把一般技术/商务要求实质性化。
- 采购需求：是否完整明确，是否存在品牌、型号、专利、特定路线、特定检测报告指向。
- 评分办法：价格分、技术分、商务分权重；证书、业绩、人员、奖项、方案类评分占比。
- 采购方式和程序：是否存在框架协议、合作创新采购、评定分离、核心产品、同品牌投标等特殊规则。
- 证明材料：是否要求官网截图、制造商盖章、检测报告、社保、学信网、职称/职业资格查询等。
- 合同履约：验收、付款、违约、保密、知识产权、数据归属、转包分包、运维服务。
- 地方平台规则：深圳智慧平台、文件制作机器码、信用信息、诚信承诺等。

### 7. 初步风险画像

只做方向判断，不下最终结论：

- 资格条件风险高/中/低
- 采购需求风险高/中/低
- 评分办法风险高/中/低
- 政府采购政策风险高/中/低
- 合同履约风险高/中/低
- 证明材料和程序要求风险高/中/低
- 采购方式和品目属性风险高/中/低
- 高风险入口：人员证书、供应商认证、奖项荣誉、同类业绩、本地化、制造商授权、软件著作权、实质性条款、技术参数指向。

## 画像路由规则

文件画像完成后，应根据画像标签调用对应动作包或专项知识。

### 物业管理路由

当画像命中以下任一信号时，调用 [[wiki/20-知识点/物业管理动作化审查包]]：

- 采购品目或项目名称包含物业管理；
- 服务内容包含保洁、安保、绿化、维修维护、会务客服、秩序维护、设备设施管理、建筑机电运维；
- 采购人为学校、医院、法院、机关等公共服务或公共安全场景，且采购对象为长期现场服务；
- 评分办法集中出现物业人员、项目经理、保洁主管、安保主管、电工、医辅、机电运维人员、物业认证、物业业绩、物业荣誉等。

路由后应附加以下画像标签：

```text
品类=物业管理
标的属性=服务
服务属性=长期现场服务
场景=学校物业/医院物业/法院和机关物业/建筑机电物业/一般物业
高频风险入口=人员证书; 供应商认证; 同类业绩; 方案主观分; 合同付款验收; 分包联合体; 实质性条款
```
