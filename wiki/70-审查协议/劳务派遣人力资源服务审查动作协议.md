# 劳务派遣人力资源服务审查动作协议

类型:: 审查协议
状态:: 试运行
主题:: 劳务派遣; 人力资源服务; 招标文件合规审查; 动作任务包
适用地域:: 全国
适用品目或场景:: 劳务派遣; 人力资源服务; 岗位外包; 招聘服务; 人员服务
关联依据:: [[wiki/10-法规依据/劳务派遣人力资源服务采购法规标准依据]]
关联动作包:: [[wiki/20-知识点/劳务派遣人力资源服务动作化审查包]]
关联质量门:: [[wiki/70-审查协议/质量门规则]]

## 1. 定位

本协议把劳务派遣和人力资源服务类采购文件的审查动作固定为可执行任务包。

## 2. 动作清单

### 人力资源-A01 服务属性和用工边界

动作ID:: 人力资源-A01
必读章节:: 项目概况；采购需求；合同
触发信号:: 劳务派遣；岗位外包；人力资源；招聘；人员服务；用工管理
必须检查:: 服务类型、用工管理、人员指挥和劳动责任边界是否清楚
关联审查点:: [[wiki/25-风险审查点/劳务派遣和岗位外包边界不清]]；[[wiki/25-风险审查点/采购品目和标的属性识别错误]]
未命中也必须记录:: 是

### 人力资源-A02 许可资质匹配

动作ID:: 人力资源-A02
必读章节:: 资格条件；特定资格；投标文件格式
触发信号:: 劳务派遣；劳务派遣经营许可证；人力资源服务许可证；备案；职业中介；特定资格要求无
必须检查:: 许可资质是否与服务内容匹配；劳务派遣项目是否缺少劳务派遣经营许可；普通外包项目是否许可错配或过度
关联审查点:: [[wiki/25-风险审查点/劳务派遣经营许可缺失或未作为准入条件]]；[[wiki/25-风险审查点/劳务派遣人力资源许可要求错配或过度]]；[[wiki/25-风险审查点/资格条件违法或过度]]
未命中也必须记录:: 是

### 人力资源-A03 人员条件和证书

动作ID:: 人力资源-A03
必读章节:: 岗位要求；人员配置；评分办法
触发信号:: 年龄；学历；专业；性别；户籍；经验；证书；社保
必须检查:: 人员条件是否与岗位职责相关，是否身份或学历过度
关联审查点:: [[wiki/25-风险审查点/人员学历职称证书异常加分]]；[[wiki/25-风险审查点/人员年龄性别身高形象限制]]
未命中也必须记录:: 是

### 人力资源-A04 工资社保和服务费报价

动作ID:: 人力资源-A04
必读章节:: 报价表；成本明细；付款；合同
触发信号:: 工资；社保；公积金；福利；加班；管理费；服务费；税费
必须检查:: 法定劳动成本、服务费和税费是否清楚，报价是否可能无法覆盖成本
关联审查点:: [[wiki/25-风险审查点/人员工资社保和服务费报价边界不清]]；[[wiki/25-风险审查点/价格分和报价规则异常]]
未命中也必须记录:: 是

### 人力资源-A05 人员替换、退回和考核

动作ID:: 人力资源-A05
必读章节:: 人员管理；考核；替换；退回；合同
触发信号:: 退回；替换；缺岗；离职；考核；扣款；补岗
必须检查:: 人员退回、替换、缺岗、考核和扣款规则是否清楚
关联审查点:: [[wiki/25-风险审查点/考核扣款和验收规则单方或不清]]；[[wiki/25-风险审查点/合同条款与采购需求不一致]]

动作ID:: 人力资源-A06
必读章节:: 合同；保密协议；劳动争议；工伤责任
触发信号:: 工伤；劳动争议；仲裁；保密；全部责任；无限赔偿
必须检查:: 劳动争议、工伤、保密和赔偿责任是否边界清楚
关联审查点:: [[wiki/25-风险审查点/劳动争议工伤和用工责任边界不清]]；[[wiki/25-风险审查点/合同条款与采购需求不一致]]

### 人力资源-A07 业绩和平台资源评分

动作ID:: 人力资源-A07
必读章节:: 商务评分；业绩证明；平台资源
触发信号:: 同系统业绩；本地人才库；招聘渠道；特定行业；人力资源经验
必须检查:: 业绩和平台资源是否限定地域或特定采购人
关联审查点:: [[wiki/25-风险审查点/同类业绩限定过窄]]；[[wiki/25-风险审查点/本地服务网点或本地化条件]]

### 人力资源-A08 合同专用条款和验收闭环

动作ID:: 人力资源-A08
必读章节:: 合同；验收；付款；响应文件格式
触发信号:: 服务类合同参考文本；付款条件；验收要求；工资发放；劳资纠纷；工伤；人员替换
必须检查:: 合同是否固化劳务派遣专用条款，验收是否对应工资社保、人员到岗、替换退回、争议处理和付款资料
关联审查点:: [[wiki/25-风险审查点/合同关键空白或模板错配]]；[[wiki/25-风险审查点/劳动争议工伤和用工责任边界不清]]；[[wiki/25-风险审查点/付款方式和支付时限不明确]]
未命中也必须记录:: 是
